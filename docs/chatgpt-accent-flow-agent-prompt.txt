Reference model

Accent is not the same as primary text color or the background palette. It branches into distinct roles:
  selected accent identifier/custom hex
    -> mode/preset-aware base accent
    -> solid action + hover + pressed + on-solid text
    -> readable link/accent foreground
    -> soft selected surface + border
    -> user-message surface + user-message text
    -> text-selection/attribution highlight
    -> checked control fill + contrasting mark/thumb
    -> optional explicitly supported visualization roles

Do not assign one hex to all of these. Do not replace palette.primary.main with the accent: ordinary buttons and text are currently deliberately neutral.
